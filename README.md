TyreXpress – Tyre Services Website

This is a responsive website for TyreXpress, a tyre service and automotive business. The website provides information about tyre products, services, company background, and contact details.

Project Overview

TyreXpress is a static website built with HTML, CSS, and JavaScript. It is designed to be user-friendly, mobile responsive, and visually consistent with the brand colors dark blue and orange.

Features

Home Page: Introduces TyreXpress to visitors.

Services Page: Displays the range of tyre and automotive services.

Tyres Page: Shows popular tyre categories with images and descriptions.

About Page: Provides company background, mission, and community involvement.

Contact Page: Includes a modern, responsive contact form and company contact information.

Contact Form

The contact page includes the following fields:

First Name

Last Name

Age

Gender

Reason for Contact (checkbox options)

Email Address

Phone Number

Message Box

The page also displays company contact information and a link for quick quote requests via email.

Responsive Design

The site adapts to different screen sizes including mobile, tablet, and desktop.

Future Improvements

Add a backend for handling form submissions.

Store customer inquiries in a database.

Add a blog or news section for tyre tips and promotions.

Include interactive location services using a map API.
